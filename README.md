# 🚀 BoeMish Installer

**BoeMish Installer** — это автономная, лёгкая и стильная утилита для быстрого развёртывания программного обеспечения и портативного софта в ОС Windows. Проект разработан на Python с использованием интерфейса CustomTkinter и не требует внешних зависимостей при запуске.

Инструмент идеально подходит для системных администраторов, эникеев и мастеров по обслуживанию ПК для работы с загрузочных флешек и внешних накопителей.

---

## ✨ Ключевые возможности

* **📂 Динамический каталог:** Автоматическое сканирование папки `catalogue/` и группировка программ по категориям первого уровня.
* **📦 Поддержка различных форматов:** Запуск и тихая установка `.exe`, `.msi`, `.bat`, `.cmd`, а также автоматическая распаковка `.zip` архивов с портативным софтом.
* **🖼 Native Icon Extraction:** Автоматическое извлечение оригинальных иконок из исполняемых файлов через Windows API в высоком качестве (40x40px).
* **⚙️ Гибкая настройка ключей:** Удобное сохранение параметров тихой установки (`/S`, `/SILENT`, `/qn`) в локальном конфигурационном файле `apps_config.json`.
* **⚡ Фоновое выполнение и лог:** Многопоточная установка без подвисания интерфейса с отслеживанием процессов (`process.wait()`) и выводом последних 5 успешно установленных программ.
* **🎨 Современный GUI:** Минималистичный тёмный интерфейс с фиолетовыми акцентами, поиском по названию и встроенной системой уведомлений.

## 📥 Установка и запуск

Программа является полностью **портативной (Portable)** и не требует предварительной установки в систему.

1. Перейдите в раздел **[Releases](../../releases)** и скачайте последний архив с приложением (`.zip`).
2. Распакуйте содержимое архива в любую удобную папку на компьютере или прямо на **USB-флешку**.
3. Запустите исполняемый файл приложения.

> ⚠️ **Важно:** Для выполнения тихой установки программ и распаковки архивов в системные директории запускайте утилиту от **имени Администратора** (правый клик по `.exe` ➔ *Запуск от имени администратора*).

## 📖 Как пользоваться программой

### 1. Наполнение каталога
Все программы и архивы хранятся в папке `catalogue/`, которая находится рядом с исполняемым файлом:
* Создавайте внутри `catalogue/` подпапки для категорий (например: `Системные`, `Браузеры`, `Мультимедиа`).
* Помещайте нужные установочные файлы (`.exe`, `.msi`, `.bat`, `.cmd`) или портативные архивы (`.zip`) в соответствующие папки.
* Утилита автоматически сосканирует каталог и сгруппирует софт по категориям при запуске.

### 2. Настройка ключей тихой установки
Для автоматической («тихой») установки приложений без всплывающих окон:
* Нажмите кнопку **«⚙️ Ключи»** напротив нужной программы в списке.
* Введите ключи тихой установки (например, `/S` для NSIS, `/SILENT` для Inno Setup или `/qn /norestart` для MSI-файлов).
* Настройки автоматически сохранятся в файл `apps_config.json`.

### 3. Процесс установки
* **Одиночная установка:** Нажмите кнопку **«Установить»** напротив конкретного приложения.
* **Пакетная установка:** Отметьте галочками несколько программ и нажмите зеленую кнопку **«⚡ УСТАНОВИТЬ ВЫБРАННЫЕ»** в левом меню.
* За ходом работы можно следить через блок **«Последние установленные»**, который в реальном времени отображает историю завершенных процессов.

## 🛠 Технологический стек

* **Язык:** Python 3.8+
* **GUI:** CustomTkinter, Tkinter
* **Системные вызовы:** WinAPI (через `ctypes` & `pywin32`)
* **Архивация:** `zipfile`
* **Сборка:** PyInstaller
