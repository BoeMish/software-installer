# 🚀 BoeMish Installer

**BoeMish Installer** — это автономная, лёгкая и стильная утилита для быстрого развёртывания программного обеспечения и портативного софта в ОС Windows. Проект разработан на Python с использованием интерфейса CustomTkinter и не требует внешних зависимостей при запуске.

Инструмент идеально подходит для системных администраторов, эникеев и мастеров по обслуживанию ПК для работы с загрузочных флешек и внешних накопителей.

---

## ✨ Ключевые возможности

* **📂 Динамический каталог:** Автоматическое сканирование папки `catalogue/` и группировка программ по категориям первого уровня.
* **📦 Поддержка различных форматов:** Запуск и тихая установка `.exe`, `.msi`, `.bat`, `.cmd`, а также автоматическая распаковка `.zip` архивов с портативным софтом.
* **🖼 Native Icon Extraction:** Автоматическое извлечение оригинальных иконок из исполняемых файлов через Windows API в высоком качестве (40x40px).
* **⚙️ Гибкая настройка ключей:** Удобное сохранение параметров тихой установки (`/S`, `/SILENT`, `/qn`) в локальном конфигурационном файле `apps_config.json`.
* **⚡ Фоновое выполнение и лог:** Многопоточная установка без подвисания интерфейса с отслеживанием процессов (`process.wait()`) и выводом последних 5 успешно установленных программ.
* **🎨 Современный GUI:** Минималистичный тёмный интерфейс с фиолетовыми акцентами, поиском по названию и встроенной системой уведомлений.

---

## 🛠 Технологический стек

* **Язык:** Python 3.8+
* **GUI:** CustomTkinter, Tkinter
* **Системные вызовы:** WinAPI (через `ctypes` & `pywin32`)
* **Архивация:** `zipfile`
* **Сборка:** PyInstaller
